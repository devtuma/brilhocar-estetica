O que é o BrilhoCar System?

O BrilhoCar Estética Automotiva é um sistema completo de gestão de agendamentos para clínicas de estética automotiva. Ele permite que clientes agendem serviços online, realizem pagamento via PIX, e acompanhem o status do trabalho em tempo real.

📅
Agendamento Online
Clientes escolhem serviços, veículo, data e horário disponível
💳
Pagamento PIX
Integração com Asaas para pagamento instantâneo via PIX
📱
Acompanhamento Real-time
QR Code para check-in e status atualizado em tempo real
⚙️
Painel Administrativo
Gerenciamento completo de serviços, horários e agendamentos

Passo 1: Acessar o Site

O cliente acessa o site da BrilhoCar através da URL principal. Na página inicial (Home), ele encontra:

  • Banner de promoções ativas (quando houver)
  • Hero section com título e chamada para ação
  • Lista de serviços disponíveis com preços
  • Depoimentos de clientes
  • Botão para agendar ou falar via WhatsApp
ℹ️
Dica
Os serviços são carregados dinamicamente do banco de dados. Isso significa que o admin pode adicionar/remover serviços sem alterar o código.
Passo 2: Clicar em "Agendar"

O cliente clica no botão principal de agendamento. Pode ser:

  • Botão "Agendar Meu Horário" no hero
  • Botão "Ver todos e agendar" na seção de serviços
  • Link direto: /booking

Isso leva o cliente para a página de agendamento.

Passo 3: Selecionar Serviços

Na página de Booking, o cliente vê uma lista de serviços disponíveis. Para cada serviço, são exibidos:

  • Nome do serviço
  • Preço base
  • Duração estimada
  • Indicação de serviço em destaque (⭐)

O cliente pode selecionar múltiplos serviços. O total é calculado automaticamente.

Passo 4: Informar Dados Pessoais

Após selecionar os serviços, o cliente preenche:

  • Nome completo
  • Selecionar veículo (cadastrado anteriormente) ou informar novo
  • Modelo e Placa do veículo
🔑
Login Automático
Se o cliente estiver logado (via Firebase Auth), o nome e veículos são preenchidos automaticamente.
Passo 5: Escolher Data e Horário

O cliente seleciona a data desejada. Ao selecionar, um picker de horários aparece mostrando:

  • Horários disponíveis em verde
  • Horários ocupados (riscados em vermelho)
  • Horários já reservados mostram tooltip com info

⚠️
Bloqueio de Horário
Ao selecionar um horário, ele é reservado temporariamente (10 minutos) até o pagamento ser confirmado. Isso evita conflitos.
Passo 6: Confirmar e Ir para Pagamento

Após preencher todos os dados, o cliente clica em "Confirmar e Ir para Pagamento". O sistema:

  1. Cria a Ordem de Serviço (OS) com número único (ex: BC-2026-123456)
  2. Salva o agendamento no Firestore com status "Aguardando Pagamento"
  3. Redireciona para a página de pagamento PIX
💳

Pagamento via PIX

Como funciona a integração com o gateway Asaas

🔍

Resumo do Agendamento

Na página de pagamento, o cliente vê um resumo completo:

  • Data e horário agendado
  • Veículo (modelo e placa)
  • Lista de serviços selecionados
  • Valor total
📱

QR Code PIX

O sistema gera um QR Code PIX com:

  • Valor exato do agendamento
  • Chave PIX configurada no painel admin
  • Validade de 10 minutos

Confirmação Automática

O fluxo de confirmação funciona assim: 

┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│   Cliente    │      │    Asaas     │      │  Firebase    │
│   paga PIX   │ ──── │  confirma    │ ──── │  webhook     │
└──────────────┘      └──────────────┘      └──────────────┘
                                                    │
                                                    ▼
                                            ┌──────────────┐
                                            │  Cloud Fn    │
                                            │ atualiza OS  │
                                            └──────────────┘
                                                    │
                                                    ▼
                                            ┌──────────────┐
                                            │  Cliente     │
                                            │ é notificado │
                                            └──────────────┘
🎉
Real-time
A página de pagamento escuta alterações no Firestore. Quando o webhook atualiza o status, a página detecta automaticamente e redireciona para acompanhamento.
⏱️

Tempo de Expiração

O QR Code PIX expira em 10 minutos. Se o pagamento não for confirmado:

  • O slot é liberado automaticamente
  • O cliente pode tentar novamente
  • Uma Cloud Function scheduled (a cada 5 min) limpa pagamentos expirados
📊

Acompanhamento do Serviço

Como o cliente acompanha o status do trabalho

🔖

QR Code do Agendamento

Após o pagamento, o cliente acessa a página "Meus Veículos" (/track) e encontra:

  • Lista de todos os agendamentos
  • QR Code único para cada OS
  • Botão para baixar ou enviar via WhatsApp

Timeline de Status

O cliente acompanha o progresso através de uma timeline visual:

Status Descrição Quando ocorre
⏳ Aguardando Pagamento Aguardando confirmação do PIX Após criar agendamento
📅 Agendado Pagamento confirmado, aguardando dia Após webhook do Asaas
🚗 Veículo Recebido Carro chegou na clínica Ao escanear QR Code na recepção
🔧 Serviço Iniciado Trabalho começou Quando admin inicia o serviço
✅ Finalizado Serviço concluído Quando admin marca como pronto
📦 Entregue Carro devolvido ao cliente Último passo do fluxo
🔄

Reagendamento

Se o cliente precisar reagendar, ele pode solicitar diretamente pela página de acompanhamento (antes do serviço ser iniciado). O admin recebe a solicitação e pode aceitar ou recusar.
