FAQ - Perguntas do Cliente

Perguntas frequentes feitas por clientes

Como faço para agendar um serviço?
Acesse o site, clique em "Agendar", selecione os serviços desejados, preencha seus dados e escolha a data e horário disponível. Após confirmar, você será direcionado para o pagamento via PIX.
Posso agendar para outro dia?
Sim! Na etapa de seleção de horário, você pode escolher qualquer data futura que tenha disponibilidade. Datas passadas ou bloquadas pelo admin não aparecem.
Como funciona o pagamento via PIX?
Após criar o agendamento, um QR Code PIX é gerado com o valor exato. Basta abrir o app do seu banco, escanear o código e confirmar o pagamento. A confirmação é automática e imediata.
O QR Code do PIX expira?
Sim, o QR Code expira em 10 minutos. Se o tempo acabar, você pode gerar um novo tentando agendar novamente. O horário fica liberado automaticamente.
Como acompanho o status do meu serviço?
Após o pagamento, acesse "Meus Veículos" no menu. Lá você verá a timeline com todos os status (Agendado → Recebido → Em Serviço → Finalizado → Entregue).
O que é o QR Code que recebi?
O QR Code é a identificação do seu agendamento. Apresente-o na recepção da clínica. Ele pode ser baixado como imagem ou enviado via WhatsApp.
Posso reagendar meu horário?
Sim, enquanto o serviço ainda não foi iniciado, você pode solicitar reagendamento pela página "Meus Veículos". A solicitação é analisada pela equipe.
Como funciona o check-in?
Ao chegar na clínica, apresente o QR Code na recepção. A equipe escaneia e confirma a entrada do seu veículo. Você recebe uma notificação via WhatsApp.
Posso adicionar mais serviços depois?
Entre em contato via WhatsApp para adicionar serviços a um agendamento existente. Não é possível via sistema.
O que acontece se eu cancelar?
Cancelamentos devem ser feitos com antecedência. Entre em contato via WhatsApp. O reembolso (se aplicável) segue as políticas da clínica.

FAQ - Perguntas do Administrador

Dúvidas comuns sobre gerenciamento do sistema

Como adiciono um novo serviço?
Acesse o painel admin → "Serviços" → clique em "Novo Serviço". Preencha nome, preço, duração, descrição e ícone. Salve para publicar.
Como bloqueio um dia específico?
Vá em "Horários" → "Dias Fechados" → adicione a data. Ela não aparecerá para clientes. Você também pode bloquear intervalos específicos durante o dia.
Como configuro o horário de funcionamento?
Em "Horários", configure abertura e fechamento para cada dia da semana. Saturday pode ter horários diferentes de weekdays.
O que acontece quando um pagamento PIX é confirmado?
O webhook do Asaas notifica a Cloud Function, que atualiza o status no Firestore. A página de pagamento detecta em tempo real e redireciona o cliente.
Como删除 um agendamento?
Na tabela de agendamentos, clique no ícone de lixeira. Será solicitado um motivo (opcional). A exclusão é registrada no histórico de audit logs.
Posso excluir múltiplos agendamentos de uma vez?
Sim! Selecione os agendamentos usando os checkboxes na tabela, depois clique em "Excluir Selecionados". Todos serão registrados no log.
Como funciona o scanner de QR Code?
Clique em "Check-in" no menu. Ative a câmera e escaneie o QR do cliente. O sistema mostra os detalhes e oferece avançar o status.
Posso customizar as cores do site?
As cores primárias estão no Tailwind config. Para branding white-label, será necessário modificar a paleta (verde #00e676, dourado #D4AF37).
Como adiciono um novo admin?
Por enquanto, adicionamos admins diretamente no Firestore na collection "admins". Future: painel de gerenciamento de admins.
O sistema envia emails automáticos?
Atualmente não há emails automáticos. Notificações são via WhatsApp (check-in) e atualização em tempo real no site.

Como Salvar como PDF

Instruções para exportar os manuais

🖨️

Método 1: Imprimir do Navegador

  1. Abra o arquivo HTML no navegador (Chrome/Edge recomendado)
  2. Pressione Ctrl + P (ou Cmd + P no Mac)
  3. Em "Destino", selecione "Salvar como PDF"
  4. Marque "Gráficos de fundo" para manter as cores
  5. Clique em "Salvar"
🔄

Método 2: Unificar em Um PDF

Para criar um único PDF com todas as partes:

  1. Salve cada parte como PDF separadamente
  2. Abra o Adobe Acrobat ou similar
  3. Use "Combinar arquivos" para unir
  4. Ou use ferramentas online como ilovepdf.com/merge-pdf
