Acesso ao Painel

Como fazer login e ativar permissões de administrador

Passo 1: Acessar a página de Login

Navegue até /login no site. Você verá a tela de autenticação do Firebase.

Passo 2: Fazer login com Google

Clique no botão "Continuar com Google" e selecione sua conta. Isso usa Firebase Authentication.

ℹ️
Conta Google
O sistema usa autenticação via Google. Qualquer pessoa com conta Google pode fazer login, mas apenas admins têm acesso completo.
Passo 3: Acessar /admin

Após login, acesse /admin na URL. Você verá o painel administrativo.

⚠️
Primeiro Acesso
Na primeira vez, você verá um aviso amarelo pedindo para "Ativar Permissões Admin". Clique no botão para se tornar admin.
Passo 4: Bootstrap Admin

O sistema chama uma Cloud Function que registra seu UID no Firestore na collection admins. Após confirmar, recarregue a página.

Configurar PIX

Integrar gateway de pagamento Asaas

🔑

Credenciais do Asaas

Para ativar pagamentos PIX, configure:

🔐
API Key
Chave de API do painel Asaas (sandbox ou produção)
🧪
Ambiente
Sandbox (testes) ou Produção (real)
📧
Webhook URL
URL para receber notificações de pagamento
⚠️
Segurança
A API Key é armazenada de forma segura no Firestore. Em produção, considere usar Cloud Functions para operations sensíveis.
