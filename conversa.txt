# CLEAN CAR — Arquitetura do Sistema MVP

## 1. Objetivo do MVP

Criar um sistema web/app para estética automotiva com:

* Agendamento online
* Geração automática de QR Code
* Check-in por QR Code na entrada
* Controle de status do serviço
* Envio de mensagens pelo WhatsApp
* Histórico do cliente e veículo
* Painel administrativo para gestão diária

---

# 2. Perfis de Usuário

## Cliente

Pode:

* Agendar serviço

# 7. Fluxo do QR Code

## Quando o cliente agenda

O sistema gera:

OS exemplo:

CC-2026-000001

QR Code com:

{
"appointmentId": "abc123",
"osNumber": "CC-2026-000001",
"plate": "ABC1D23"
}

O QR Code não deve conter dados sensíveis completos.

---

## Na entrada

1. Funcionário abre tela “Scanner QR”
2. Escaneia QR Code
3. Sistema busca appointmentId
4. Abre ficha do agendamento
5. Funcionário confirma:
   “Dar entrada no veículo”
6. Status muda para:
   “Veículo recebido”
7. WhatsApp é enviado ao cliente

# 11. Regras de Negócio

1. Todo agendamento deve gerar OS única.
2. Todo agendamento deve gerar QR Code.
3. QR Code só pode ser usado para um check-in.
4. Status deve ser registrado em histórico.
5. Cliente deve receber mensagem quando status mudar.
6. Apenas operador ou admin pode mudar status.
7. Apenas admin pode alterar preço dos serviços.
8. Fotos antes/depois ficam vinculadas à OS.
9. Veículo entregue encerra o atendimento.
10. Histórico nunca deve ser apagado.
